## ℹ️ About HDO PRO

HDO PRO is a private, community-driven Android and TV media player project inspired by the original HDO Box.

### Features

* 🚫 Ad-Free Experience
* 🔒 Privacy Focused
* ⚡ Performance Optimizations
* 📱 Android Support
* 📺 Android TV Support
* 🎨 Improved User Interface

> HDO PRO is an independent community project and is not affiliated with the original HDO Box project.

---

## 📱 Mobile Version

Built for Android phones and tablets.

## 📺 TV Version
